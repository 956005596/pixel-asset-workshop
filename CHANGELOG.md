# Changelog

## 0.1.0 — 2026-10-14

Initial public snapshot of the offline Pixel Asset Workshop:

- Self-contained Canvas character editor and procedural skill-effect composer.
- 32–512 px characters; 17-joint image rigging and baked sprite animation.
- Local structured-request CLI and optional stdio MCP tools.
- Editable project/recipe JSON and transparent PNG/playback exports.
- English/Chinese overview, MIT license, reproducible checks and procedural example.

Private references, historical local verification bundles and uploaded artwork
are excluded. This release does not claim final character-animation acceptance,
public adoption metrics, or verified game-engine integration.
