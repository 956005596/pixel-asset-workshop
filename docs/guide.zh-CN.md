# 像素素材工坊

## 大尺寸特效画布 · 2026-10-11

“特效 → 生成 → 画布尺寸”新增256×256、512×512，仍支持最多32帧。大画布默认自动缩小预览，0.25/0.5倍仅用于查看，PNG导出保持真实尺寸。程序特效按新尺寸重新绘制；人物画布同样支持32、48、64、96、128、256、512，导入特效图片仍保留64像素素材格，放大不会补充细节。

512像素、32帧原始RGBA帧缓冲约32 MiB（不含图集、临时画布和浏览器其他内存）。实际耗时随部件、粒子、拖尾和设备变化；预览画布最大边长1536，超出时相应倍率不可选。512项目与配方需使用更新后的HTML，旧版可能拒绝读取；小尺寸项目仍可恢复。


## 紧凑界面 · 2026-10-11

- **生成**：选择完整技能或基础特效，调整颜色、尺寸、帧数与帧率；“旋转、缩放与爆炸”需要时再展开。
- **部件**：时间条点选部件；“外观”设置形状、运动、数量，“时序”设置出现时间，“变化”设置缩放、旋转与叠加。名称与图层顺序折叠收纳，不再同时展示两套部件列表。
- **配方**：保存、载入自己的效果，导入或导出配方。关闭前仍须保存项目 JSON。
- 大预览旁可播放和切换背景；默认收起逐帧列表，点击“展开逐帧查看”再检查单帧。播放时大预览真实换帧；点选帧会暂停，以选中帧为单帧导出对象。
- 支持0.25、0.5、1、2、3倍等预览缩放，大画布默认缩到可完整显示。桌面参数栏独立滚动，手机宽度下顺序排列。


双击 **index.html**，即可离线使用像素编辑、本地人物模板和特效组合。样式、脚本和演示内嵌于单文件。建议桌面版 Chrome / Edge 等现代浏览器。无需启动服务、填写密钥或安装软件。

## 先做技能特效

打开后默认进入 **特效** 工作区，显示“烈焰爆破”的完整阶段示例。

1. 在“技能特效 · 从完整效果开始”中选烈焰爆破、冰晶冲击、雷电落击、回春法阵或风刃连斩，点击 **生成这套技能**。
2. 模块分别负责蓄力、聚能、释放、命中、消散。点时间条选中部件，调整起始/结束大小、旋转圈数、变化节奏及叠加方式。也可一键放到蓄力、释放、命中或消散时段。
3. 原有形状增加符文法阵与棱面冰晶；仍可修改数量、位置、颜色、扩散和拖尾。不是只能使用五套现成技能，部件可删除、复制和重组。
4. 点击 **＋ 导入自己的特效 PNG / 图集**，给组合增加自己的图像。透明单图直接导入；等尺寸、无间隔图集须填写每格宽/高和实际帧数。按从左到右、从上到下读取，最多16帧；源图不修改。每帧等比例缩至最长边64像素，居中放入透明64×64格。导入素材保留原色，颜色选择只影响程序图形。
5. 图片可多份散射、旋转、缩放、飘动或叠加；图集在模块的持续时间内播放一次，结束保持最后一帧。单张图片的运动来自这些变换，不会自动补画新的物体形状。
6. 保存项目或自己的配方，再导出透明PNG和播放JSON。五种完整技能默认128像素、24帧、24 FPS，约1秒；播放JSON标记为单次，预览仍循环便于检查。切换现成预设会恢复其默认循环标记。

画布外的部分会裁切。复杂技能建议16–24帧；此版时间条用于选择和查看部件，精确时刻用滑块设置，不支持拖拽时间条。程序图形和自己的素材都能保存进配方；配方文件上限4 MiB，项目上限192 MiB。

**离开前保存项目JSON。** 可复现的程序化请求位于 `examples/ice-burst.json`，运行后会导出图集、播放信息和可编辑项目；实现保持自包含、离线运行。

## 人物与其他离线功能

### 1. 套模板生成移动序列帧

切换“人物”工作区可看到原创日式幻想人物“青岚剑士”的 64 像素待机演示。

在“人物”工作区左上角点击 **生成走路 / 跑步序列帧**。默认套用四方向走路模板；点击“套用跑步模板”即可切换。两种模板都一次生成正面、背面、向左、向右各 6 帧，共 24 帧，不需要画序列帧。

走路默认 10 FPS，跑步默认 12 FPS。图集会自动每行 6 帧，四个方向分别占一行。预览中可以选择动作和朝向。导出的是原地步行 / 跑步的循环，人物在游戏中的位置移动由游戏逻辑控制。

可先点击 **青岚剑士 / 月辉法师 / 绯羽旅人** 选外观起点，再调整配色和装备。人物画风默认“日式幻想 · 细节版”，原生绘制于 64×64，包含发束、眼睛高光、衣领、腰带、护甲和金属武器细节；也可以选“简洁像素 · 原版”。

生成尺寸可选32、48、64、96、128、256、512；内置细节模板原生64像素，放大不会增加细节，缩小会减少细节。生成时会明确提示替换尺寸，可撤销；追加模式沿用原画布尺寸。

如果要生成攻击、施法或自选动作，点击 **换装、攻击与更多动作**：

- 选肤色、发色、服装颜色、点缀色；选短发 / 长发 / 兜帽，短袍 / 长外套 / 护甲，剑 / 斧 / 法杖 / 空手。
- 选单个朝向，或“四个朝向 · 一次生成”。
- 勾选待机、走路、跑步、近战攻击、施法；每个动作可选 4、6 或 8 帧。预览会自动播放。
- 点击“生成并放入人物画布”。默认替换人物工作区，先确认，特效与配方保留；可以用人物撤销恢复。
- 若要增加另一个朝向或动作，重新打开生成器并勾选“追加”。追加保留原帧，帧率会对人物的所有动作生效。

生成器使用原创的人物模板，改变手臂、腿和武器的姿势。输出分为双腿、服装、双臂、头发与面部、武器五个图层，生成后仍能手绘修改。此入口使用内置外观。自己的素材请使用下面的“让我的人物素材动起来”入口并标记部位。

### 2. 用自己的素材生成走路 / 攻击

点击 **让我的人物素材动起来**：

1. 选择“导入人物 PNG”，或使用“当前合成帧 / 当前图层”。建议透明、四肢可见的直立人物；原图文件不修改。方形PNG按相应参考尺寸导入，参考画布最高512像素，不再固定缩至64；其他比例会裁去透明边缘、保留比例并留边距。参考尺寸取源图及当前人物画布所需尺寸，最低64、最高512。
2. 选择头、躯干、画面左/右手臂、左/右腿；在图上拖动框选。参考框仅为起点，需要根据你的人物调整。
3. 切到“点击设置关节”：手臂放肩部，腿放髋部，头放颈部。若有武器，启用“有独立武器”，框出武器并把关节放在握柄，选择跟随哪只手。
4. 选待机、走路、跑步或攻击；选原图为正面/背面直立还是朝左/右的侧面，预览自动播放。这里只生成原图这一朝向，不会从正面创造出新的背面。
5. 点击“生成并放入人物画布”。输出分区图层和真正的局部动作帧；使用的是你导入图的像素。默认替换人物工作区，可撤销；“追加”保留已有帧，输出尺寸沿用当前画布。

可以先“保存分区，不改变现有帧”，再保存项目JSON。原始参考像素、各分区、关节、武器绑定与动作参数都存在项目中，下次不用重新标记。分区修改可在窗口内撤销最近8步；生成和保存分区可以用人物撤销。

重叠的框按武器→头→双臂→双腿→躯干分配像素；没有框住的像素保留在躯干。右側“实际切分”帮助检查是否误切。四肢分区为空时不能生成走路/跑步；攻击手为空时不能生成攻击。

**骨骼模式支持肩/肘/手腕、髋/膝/脚踝/脚尖等17个节点，通过骨骼驱动蒙皮网格。** 新人物默认启用；旧项目可勾选“使用骨骼控制动作”升级。先校正分区，再选择骨骼节点点击原图定位。腿部两段IK控制屈膝和落脚，上臂/前臂独立带动手和武器；可调整步幅、抬脚高度与帧率。关闭骨骼模式后仍可使用旧分区变换。不会自动画出遮住的部位或还原复杂衣服纹理。 可用单色补齐躯干遮挡缺口，改善手臂移开后的空洞；复杂人物或大幅攻击可能需要继续手绘修改。应以动作预览为准。

输出支持32–512像素、4/6/8/12帧。512像素、7图层最多18帧，可分批追加三组各6帧动作；若只6图层，容量稍多。高清分区动作使用相同参考、朝向、分区和补色时，共用所有动作的缩放与位置；改变朝向或分区后应重新生成同套动作。追加时最后设定的帧率会对整个角色全部动作生效。若需要更多帧或图层，可降低输出尺寸。导入你有权使用的透明人物 PNG 后制作。

### 3. 照片 / 人物图片像素化

在“人物”左侧 PNG 导入区域点击 **照片 / 人物图片像素化**，选择 PNG 或 JPEG。

原图与转换结果并排预览。像素颗粒可选细 / 中 / 粗；调色板可选 8、16、24、32 色或原色。程序按图片提取调色板并映射颜色；转换尺寸跟随当前 32、48 或 64 像素画布，保留原比例并居中。

近似纯色背景可勾选“去掉边缘连接的近似纯色背景”。复杂背景建议提前准备透明 PNG。可以下载像素 PNG，也可作为新图层加入当前帧；其他帧不会自动写入。转换与应用都不修改原始图片。

**像素化只负责图片的缩小、颗粒化和减少颜色，不会为照片生成移动、攻击或四肢分层。**

### 4. 选效果，自动生成动画

切换“特效”，先选 **命中、斩击、火焰、法球、治疗、升级、爆炸** 中的一种；再选“动画过程”：

- 持续旋转，或逐渐放大 / 缩小。
- 中途爆炸。
- 先蓄力放大 → 再爆炸。
- 旋转＋放大 → 爆炸消散。

选择后自动重算全部序列帧；点击 **自动生成并播放** 从头查看。可在“调整变化参数”中修改旋转方向和圈数、开始/结束大小、爆炸时刻与范围。爆炸阶段会额外产生冲击环、飞散碎片与拖尾，随后消散；这些变化同时作用于现成预设和自己的组合。选择“效果原有动画”可以关闭附加变化。

爆炸时刻按整个动画的进度设置；帧数较少时会保留至少一帧可见爆炸，实际起始帧以界面文字为准。建议复杂组合使用 16–24 帧。旋转 / 缩放会自动给画布留出空间，因此最大可见大小还受画布边界限制。

导出透明单帧 / 全帧图集和对应播放 JSON 即可使用。保存项目或配方可恢复同一套动画；下次不用重选参数。

如果想做固定预设以外的新效果，点击 **自己组合**：

1. 给这套效果起名字。
2. 选中一个模块，选择星芒、圆点、菱形碎片、空心光环、月牙弧光或锯齿闪电。
3. 选择向外爆发、向上飘动、绕圈旋转、向中心聚集、横向划过或原地闪烁。
4. 调整颜色、数量、图形大小、移动距离和拖尾。高级设置里还可调方向、左右 / 上下位置、出场时刻、持续时长和消散方式。
5. 添加多个模块叠加，播放查看结果，生成的全部帧会自动出现在时间轴。

例如：光环＋向外爆发，再叠加菱形碎片＋爆发＋拖尾，可以组成冰霜碎裂；圆点＋向上飘动，再叠加星芒，可以做回复能量。整体大小、画布尺寸、帧数和帧率在左侧下方设置。组合器最多 6 个模块；上方覆盖下方，显隐也影响导出。

“现成预设”包含命中、斩击、火焰、法球、治疗、升级和爆炸。切换预设不会删除自己的模块，但颜色、大小与节奏等整体参数是共享的。

这是有限基础模块的组合生成器，不理解任意自然语言主题，不保证自动画出“冰龙”之类具体形象。人物与特效仍分别预览、导出。

## 把自己的特效存成配方

在“保存这套效果”中填写配方名称，展开 **保存与复用自己的配方**。现成预设加动画变化，也能作为配方保存。

- “把当前效果存为配方”记住所选效果、动画变化、模块、颜色、分布、画布与节奏。相同名称需确认覆盖。
- 选择配方后“载入”，可以恢复相同的逐帧效果。载入前先确认替换当前特效。
- “导出当前配方”下载独立配方 JSON；在其他项目中“导入配方 JSON”，再点击载入。
- 项目最多保存 12 个配方。删除配方先确认，不删除当前正在编辑的效果。

**配方库先存在当前页面内，仍须保存项目 JSON 或导出配方文件，关闭后才能找回。** 新建项目会清空当前页面的配方库，请先备份。

## 自己绘制与编辑

工具初始显示原创角色“青岚剑士”的 64 像素四帧待机演示，双腿、服装、双臂、头部和武器独立分层。也可新建32–512像素空白画布；在“人物画布”可改变已有项目的全部帧尺寸。只改画布时保持像素大小并居中，缩小会提示裁切；整套缩放采用最近邻，放大已有小图不会产生新细节。

选中图层后，用铅笔、橡皮、吸色和颜色工具编辑当前帧。上方图层覆盖下方；添加、显隐、排序和删除对全部帧生效。手绘与图层操作最多撤销8步，并受128 MiB历史预算限制；大型项目可撤销步数会减少。组合模块和配方的删除不属于人物撤销，删除前会确认。

原始 PNG 导入到当前帧、当前图层。原像素模式从左上角放置；适配模式等比例居中、最近邻缩放。X/Y 是额外偏移；超出画布先提示裁切。

复制帧可继续制作动作；洋葱皮显示上一帧的淡影。动作名属于当前帧，可在“预览动作”筛选播放。预览不改变绘图帧。大倍率画布可滚动或降低缩放。

## 保存项目与恢复

**离开前点击“保存项目 JSON”，并确认下载文件已保存。** 项目保留人物全部图层 / 帧 / 生成器配置，特效模块、参数与配方库。下次双击 HTML 后点击“打开项目”，选择项目 JSON 即可继续。

没有浏览器自动保存，不依赖 localStorage。刷新或关闭可能丢失未保存内容；浏览器关闭提示不能代替备份。保存提示只表示已发起下载，是否落盘请在下载列表确认。

未使用导入人物分区的项目保存为版本2；含分区源图的小尺寸项目保存为版本3；人物或分区参考超过64像素时保存为版本5，像素以紧凑无损格式存储。含骨骼设置的项目保存为版本6；本工具兼容读取版本1、2、3、5、6，以及旧版版本4的离线内容；版本3、5、6需使用相应新版HTML，旧版工具会拒绝读取。旧项目增加默认组合器与人物生成设置，不修改原文件；已有像素不重绘。旧版版本4若含独立高清图集、参考图或联网设置，打开前会提示：这些内容不会载入，也不会写入新备份；请保留旧项目原文件。已经放入人物画布的像素帧仍会恢复。缺少画风字段的旧版生成配置按简洁像素加载。旧版 HTML 不能读取新增的组合特效项目，请使用更新后的 HTML。

## 导出素材

- **透明 PNG · 当前帧**：原始像素尺寸，不含背景、网格或洋葱皮。
- **透明 PNG · 全帧图集**：人物合并可见图层，特效合并可见模块。帧从左到右、从上到下排列，无间距；末尾空格透明。
- **播放信息 JSON**：同名图集尺寸、帧矩形、帧率、时长与动作索引。自动人物动作保留名称和朝向；组合特效使用自己的效果名称。

每行帧数可选自动、1、4、6、8、16。更改任何内容、显隐或排列后，请重新导出 PNG 图集与播放信息。动作筛选不影响全帧导出。播放 JSON 不能作为可编辑项目备份。

## 容量与快捷键

人物最多32帧、8图层，同时最多33,554,432像素格（画布面积 × 图层数 × 帧数）。512×512、5图层支持24帧，7图层支持18帧。生成器超限会禁用生成，可减少动作 / 帧数，或取消追加。至少保留一帧、一图层。

特效限 32–512 像素、4–32 帧、6 个组合模块，每模块 1–48 个图形、0–6 段拖尾。PNG / JPEG 限 2048×2048、16 MiB；项目限192 MiB；配方文件限 4 MiB。无效或超限导入会拒绝，保留当前作品。

B 铅笔；E 橡皮；I 吸色；Ctrl/⌘ Z 撤销；Ctrl/⌘ Shift Z 重做；空格播放；左右方向键切人物帧。文本输入或对话框中快捷键停用。

## 验证与范围

公开版本的可复现检查位于 `tests/smoke.mjs`，在仓库根目录执行 `npm run check` 和 `npm test`。
覆盖五组程序特效、透明 PNG 与实际渲染逐像素对比、项目恢复、参数错误回滚、人物数据保留、
合成人物骨骼、CLI 输出保护及 MCP 协议与真实生成。检查使用临时目录及程序数据。

工具离线运行，无需账号、密钥或 API 服务。自动检查验证机制，不代表最终人物美术、
动作手感、真实触屏或游戏工程导入效果验收。历史本机测试日志与用户参考素材不随公开仓库发布。
