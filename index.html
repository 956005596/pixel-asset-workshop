2 · 分区与关节

先框出四肢，再把肩、肘、手腕和髋、膝、脚踝放到人物对应位置。骨骼带动图像弯曲；原图未画出的部分仍需补画。走跑使用脚部目标控制腿部。

补色只能填单色缺口，不能还原衣服花纹或藏在背后的部位。分区重叠时按武器、头部、双臂、双腿、躯干顺序分配像素。

从一帧到一套素材

① 在“人物”中用铅笔绘制；服装、身体、武器可分别放在图层。选择图层后只编辑当前帧的该图层。导入 PNG 也放在此处。

② 不会画动作时，点击“生成走路 / 跑步序列帧”套四方向移动模板，或点击“换装、攻击与更多动作”，自选发型、服装和武器，自动生成待机、走路、跑步、近战攻击、施法与不同朝向。动作基于原创人物模板，不是把任意导入图片自动拆成人物。也可以复制一帧，再重画四肢或武器的位置。用洋葱皮参考上一帧，按帧组织待机、走路、攻击动作。默认显示日式幻想人物“青岚剑士”的 64 像素待机演示。可选原版简洁画风；旧项目的像素不会自动变更。

③ 工坊默认打开“特效”，分为“生成 / 部件 / 配方”三个入口。在“生成”中选择完整技能或基础特效；在“部件”中点时间条，再按“外观 / 时序 / 变化”调整；在“配方”中保存、载入或导出自己的效果。旋转、缩放与爆炸按需展开。大预览上方可播放和切换背景；需要逐帧查看时，点击“展开逐帧查看”。可先选烈焰爆破、冰晶冲击、雷电落击、回春法阵、风刃连斩，自动生成完整阶段；点击部件时间条，调整大小变化、旋转和出现时间。可导入自己的透明 PNG 或无间隔图集，按每格尺寸读取1–16帧；每帧等比例放入64像素透明格，源文件保留。图片运动基于变换，不补画新形状。项目和配方都保存这些素材。也可以先选现成效果，再选择旋转、放大、缩小、爆炸或旋转放大后爆炸等动画过程，点击“自动生成并播放”。可用七种现成预设，也可选“自己组合”：用星芒、圆点、光环等形状叠加爆发、飘动、环绕等运动，拖尾与出场时间也能调整，工具自动生成全部帧。可把组合存为自己的配方，再保存项目或单独导出配方 JSON。人物与特效分别导出，本版不把两者合成。

④ 点击“保存项目 JSON”下载可靠备份；下次双击本 HTML 后用“打开项目”恢复。不会自动保存到浏览器；刷新或关闭可能丢失未保存内容。

⑤ 导出当前帧或图集，再导出播放信息。图集从左到右、从上到下，无间距，空余格透明；导出不含网格、洋葱皮或预览背景。

快捷键：B 铅笔，E 橡皮，I 吸色，Ctrl/⌘ Z 撤销，Ctrl/⌘ Shift Z 重做，空格播放，← / → 切帧。输入文字时快捷键停用。

边界：人物32–512像素，最多32帧、8图层，总像素格最多33,554,432；PNG最大2048×2048、16 MiB；项目最大192 MiB。人物撤销最多8步并受128 MiB预算限制。建议用桌面版现代浏览器。组合特效最多 6 模块，项目最多 12 配方；图片像素化支持 PNG/JPEG。特效素材PNG最大2048×2048、16 MiB，最多16帧；配方最大4 MiB。特效画布可选32–512像素，最多32帧。256/512画布会按新尺寸重新绘制程序特效；导入图片仍使用64像素素材格，放大不增加原图细节。预览缩放不改变导出尺寸。导入人物可使用“让我的人物素材动起来”，手动框选部位和关节，再生成原图朝向的走路、跑步、待机、攻击。不会自动绑定骨骼或画出被遮住的部位。特效可以选择持续旋转、放大/缩小、中途爆炸、蓄力再爆炸或旋转放大后爆炸，自动生成全部帧。相应变化会保存在项目和配方中。本版仅提供本地 2D 编辑，不含 3D 或 Maker 直接同步。
