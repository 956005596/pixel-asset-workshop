# Source and asset provenance

This initial public snapshot contains the standalone Canvas application and local
Node.js CLI/MCP adapters from the maintainer's Pixel Asset Workshop workspace.
The software has no bundled third-party runtime libraries or npm dependencies.
Node.js and Chrome/Chromium are external prerequisites with their own licenses.

The included ice-burst request and preview are generated by the procedural effects
implementation in this repository. No uploaded character reference images, private
game assets, historical output bundles, browser profiles or local execution logs
are included. The source code, documentation and this procedural example are
released under the repository's MIT license. Imported user artwork retains its
own copyright and license; exporting it does not change those rights.

During prior development, Minerva Pixel Effect Generator, PixiJS Particle Emitter
and Effekseer were consulted for capability comparison. The workspace's reference
notes report no copied code, textures or presets from those projects. They are
not dependencies or bundled assets in this release.
